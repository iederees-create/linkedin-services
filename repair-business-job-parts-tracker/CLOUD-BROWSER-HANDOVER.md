3. Add the offer: “I build custom job and inventory systems for repair businesses.” Select a supported broad category such as Custom Software Development or Business Operations only if it appears in the editor. Keep the scope and exclusions accurate.
4. Publish exactly one launch post using `posts/01-service-launch.txt`, the verified portfolio URL and `assets/images/dashboard-desktop.png` (or the PDF carousel if LinkedIn accepts it). Use alt text: “Fictional repair-business dashboard showing open jobs, awaiting parts, completed jobs and low-stock visibility.”
5. Feature the published launch post or the portfolio URL using the profile’s available Featured controls. Use `featured/title.txt`, `featured/description.txt` and `featured/target-url.txt`.
6. Leave `posts/02-workflow-example.txt` and `posts/03-featured-overview.txt` unpublished. Do not schedule them unless separately requested.
7. Verify every change. Return actual service/profile/post/Featured URLs and statuses. If a service category, PDF upload or Featured control is unavailable, complete the supported steps and report the exact limitation. Never invent a service-listing URL.
